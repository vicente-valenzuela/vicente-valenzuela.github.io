# Minimal academic website

A small, static academic website for GitHub Pages.

## How to use

1. Create a GitHub repository called `USERNAME.github.io`, replacing `USERNAME` with your GitHub username.
2. Upload these files to the repository root.
3. Edit `index.html`, `publications.html`, and `style.css` as needed.
4. Add `cv.pdf` and, optionally, `headshot.jpg` to the same folder.
5. In GitHub, go to Settings > Pages and make sure the site is being built from the main branch root.

The site should appear at `https://USERNAME.github.io/`.
